# BIOBUZZ Competition Manual — переводы для сайта

Неофициальные переводы **2026–2027 FIRST Tech Challenge Competition Manual, BIOBUZZ™ presented by RTX**,
версия **Team Update 07 (TU07)**, с официальной HTML-версии FIRST:
https://ftc-resources.firstinspires.org/ftc/game/cm-html

Языки: `ru` русский, `kk` казахский, `ky` кыргызский, `uz` узбекский, `tr` турецкий, `ro` румынский,
`zh` китайский, `es` испанский, `pt-BR` португальский (Бразилия), `fr` французский, `ar` арабский (RTL).

Русский переведён вручную. Остальные языки: глоссарий и часть глав — вручную, остальное — офлайн
машинный перевод (NLLB) с защитой терминов и разметки. Перед публикацией их стоит дать вычитать носителям.

## Что здесь

| Путь | Зачем |
|---|---|
| `<lang>/manual-<lang>.html` | Весь мануал на одном языке одним HTML-фрагментом: шапка, оглавление, 16 глав. Без `<html>/<head>/<body>` и инлайн-стилей. Картинки — `../images/…`. |
| `<lang>/chapters/NN-*.html` | Те же главы по отдельности (картинки — `../../images/…`, ссылки между главами — `NN-*.html#id`). |
| `images/` | 72 картинки из оригинала, общие для всех языков (схемы на английском, как в оригинале). |
| `manual.css` | Необязательные стили для всех языков. Всё внутри `.ftc-manual`, на остальной сайт не влияет; есть RTL для арабского. |
| `framer/FtcManual.tsx` | Готовый код-компонент для Framer (см. ниже). |
| `preview.html` | Только для локальной проверки: `python3 -m http.server` в этой папке → http://localhost:8000/preview.html?lang=ru. На сайт не нужен. |

Ссылки на правила работают как якоря: `#G204`, `#R105`, `#E101`, разделы — `#sec-10-5-5`.
Определённые термины (MATCH, ROBOT, ALLIANCE, HIVE, POLLEN…) оставлены по-английски, как в официальных
переводах FIRST; их значения — в главе 16 «Глоссарий».

## Framer

Мануал большой (0,35–0,65 МБ на язык + 3,4 МБ картинок), поэтому файлы лежат на отдельном хостинге,
а Framer подгружает нужный язык код-компонентом.

### 1. Выложить папку `dist/` на любой статический хостинг

Нужно, чтобы файлы открывались по адресу вида `https://ВАШ-ХОСТ/biobuzz/ru/manual-ru.html`
и сервер разрешал загрузку с другого домена (CORS). Подходят:

- **GitHub Pages** — бесплатно, CORS уже открыт: новый публичный репозиторий → загрузить содержимое
  `dist/` → Settings → Pages → Deploy from branch `main`. Адрес будет `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/`.
- **Netlify / Cloudflare Pages / Vercel** — перетащить папку `dist/` в панель (Netlify Drop).

Проверка: откройте `https://ВАШ-ХОСТ/…/preview.html?lang=kk` — должен показаться казахский мануал.

### 2. Добавить компонент в Framer

1. В проекте Framer: **Assets → Code → «+» → New Code File**, назовите `FtcManual`.
2. Удалите шаблонный код и вставьте содержимое `framer/FtcManual.tsx`, сохраните.
3. Создайте страницу (например `/manual/ru`), перетащите компонент **FtcManual** из Assets на страницу.
4. Справа в свойствах:
   - **Base URL** — адрес папки из шага 1, сейчас `https://arstanber.github.io/biobuzz-manual/` (стоит по умолчанию);
   - **Language** — язык.
5. Ширину поставьте **Fill** (или фиксированную), высоту — **Fit content**: высота подстроится под текст.
6. Для каждого языка — своя страница (`/manual/kk`, `/manual/ar`…) с тем же компонентом и другим Language.
   Или одна страница с переключателем через Variants.

Компонент вставляет HTML прямо в страницу (не в iframe), поэтому работают оглавление и ссылки вида
`/manual/ru#G204` — страница откроется сразу на нужном правиле. Стили берутся из `manual.css` с того же
хостинга; если хотите свои — удалите `manual.css` с хостинга и задайте стили в Framer.

Учтите: текст загружается в браузере, поэтому в превью на холсте Framer он появится, только когда
адрес уже рабочий. Поисковики индексируют такой текст хуже, чем обычный текст страницы.

### Вариант без кода: Embed (iframe)

**Insert → Embed → URL** → `https://ВАШ-ХОСТ/…/preview.html?lang=ru`. Проще, но мануал будет
в окне фиксированной высоты со своей прокруткой, а ссылки `#G204` с других страниц сайта работать не будут.

## Другие платформы

**Свой сайт.** Положите `dist/` на сервер, вставьте содержимое `ru/manual-ru.html` в страницу,
лежащую в папке `ru/` (или замените `../images/` на свой путь), подключите `manual.css`.

**Tilda / WordPress.** Картинки — на хостинг, в HTML замените префикс на полный адрес и вставьте
в блок T123 «HTML-код» (Tilda) или «Произвольный HTML» (WordPress), CSS — в `<style>` или доп. стили темы.
Для длинных страниц используйте файлы из `chapters/`.

```bash
sed -i '' 's#src="../images/#src="https://ВАШ-САЙТ/biobuzz/images/#g' ru/manual-ru.html
```

## Обновления (Team Updates)

FIRST выпускает Team Updates по четвергам. Порядок обновления (из корня проекта):

1. Скачать новый HTML и картинки, прогнать `tools/clean.py` в отдельную папку, сравнить с `work/en`
   (номера картинок Word меняет — сравнивайте текст без них).
2. Заменить `work/en` новой версией, перевести только изменившиеся абзацы во всех `work/<lang>`.
3. `python3 -I tools/sync_images.py work/en work/<lang>` — переставит номера картинок в переводе.
4. Заменить `dist/images` новыми картинками, поменять `VERSION` в `tools/build.py`.
5. `python3 -I tools/check.py work/en work/<lang>` и `python3 -I tools/build.py work/<lang> dist`
   для каждого языка, затем заново выложить `dist/` на хостинг.

Указывайте на странице, что перевод неофициальный, и давайте ссылку на оригинал FIRST.
